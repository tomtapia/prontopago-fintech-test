# @prontopago/web

Vite + React 18 + TS + Tailwind SPA.

```bash
pnpm install
pnpm dev     # :5173 (VITE_API_URL defaults to http://localhost:3000)
pnpm test    # vitest run --coverage
pnpm build   # tsc + vite build
```

Views: login form (RHF + Zod), score inquiry with 401/403/400 friendly errors.
