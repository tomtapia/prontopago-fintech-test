# Specs (SDD-first)

Spec-Driven Development is mandatory for this repo.

1. Read `docs/specs/financial-risk-inquiry/requirements.md` before coding.
2. `design.md` is normative for API contracts, types and error shapes.
3. No code without a covering requirement ID (Req-1..Req-7).
4. Tasks checklist lives in `docs/specs/financial-risk-inquiry/tasks.md`.
